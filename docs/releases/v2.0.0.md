### EDF recording and synchronization

Record AirSense 10 therapy directly to AirBridge's microSD card in
ResMed-compatible EDF format, with automatic synchronization to an SMB
share, SleepHQ, or both.

Requires an SD-capable build and a microSD card in AirBridge.

### New hardware

AirBridge now has a dedicated two-board PCB design: an interface board that
plugs into the AirSense 10 and provides power and UART, and a XIAO ESP32-S3
Plus main board with microSD for EDF recording. KiCad sources, manufacturing
files, and a printable enclosure are included.

Waveshare ESP32-S3-GEEK is also supported, using its onboard microSD slot.

M5Stamp Pico remains a legacy build without EDF recording or synchronization.

### Upgrading

AirBridge firmware updates now use HTTP through the Web UI or the Python
flasher. ArduinoOTA and its dedicated upload environments have been removed.
SmartConfig has been replaced by setup through the AirBridge access point.
