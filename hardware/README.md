# Hardware sources

User documentation: [docs/hardware.md](../docs/hardware.md).

| Path | Content |
|------|---------|
| `wiring/{xiao_sd,xiao,pico}/` | hand-wired variants (schematic only, local symbol library) |
| `pcb/board_interface/` | interface board (edge card) |
| `pcb/board_main_xiao/` | XIAO main board |
| `pcb/gerbers/` | gerbers, per board as a directory and a ZIP |
| `pcb/assembly/` | JLCPCB BOM/CPL |
| `schematics/` | PDF and PNG export of each schematic |
| `renders/` | 3D renders of the boards |
| `enclosure/xiao/` | STL for the PCB variant |
